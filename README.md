# CHUDCRAFT

The block game for Chuds.

- Free to play
- Texture packs / shaders / mods allowed without purchase
- No over the top EULA for servers
- No multiple editions (everyone plays together)
- No chat reporting
- Difficult mobs
- Tools never break
- Items dropped by player on death never despawn
- Able to walk with inventory open
- Ray traced sounds
- Player has capsule collider instead of simple box
